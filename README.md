# Paul Comaïta — 3D Artist portfolio

Source of [paulcomaita.art](https://paulcomaita.art).

## Stack

- TanStack Start (React, file-based routes in `src/routes`)
- Tailwind CSS v4 (`src/styles.css`)
- Nitro for the server build, deployed on Netlify

## Content

- Projects and case studies: `src/data/projects.ts`
- Experience timeline: `src/data/experience.ts`
- Hero video and favicons: `public/`

## Commands

```sh
bun install
bun run dev     # local dev server
bun run build   # production build
```
